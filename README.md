# Voice Cart MVP

Voice Cart is a smart, voice-command shopping assistant MVP. 

## What's Built
- **Voice Input**: Web Speech API integration, works entirely in browser (Chrome/Edge recommended).
- **Flexible NLP**: Basic command parsing for natural instructions ("add 2 apples", "clear cart").
- **Auto-Categorization**: Automatically groups items into categories like Produce, Dairy, Pantry, etc.
- **Dynamic Receipt UI**: A unique, distinctive receipt-style visual identity rather than a generic dashboard.

## Instructions
1. Run `npm install`
2. Run `npm run dev` for local development.
3. Run `npm run build` to build for production.
